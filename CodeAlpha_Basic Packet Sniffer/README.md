# Task 1: Basic Packet Sniffer

## Objective
To develop a basic packet sniffer using Python that captures and analyzes network packets.

## Description
The Basic Packet Sniffer is a Python application developed using the Scapy library. It captures live network traffic and displays important packet details such as the source IP address, destination IP address, protocol type (TCP/UDP), source port, and destination port.

## Features
- Captures live network packets
- Displays Source IP and Destination IP
- Detects TCP and UDP protocols
- Displays Source and Destination Ports
- Simple and user-friendly implementation

## Technologies Used
- Python 3
- Scapy
- Visual Studio Code
- GitHub

## Requirements
Install the Scapy library before running the program.

```bash
pip install scapy
```

## How to Run

```bash
python sniffer.py
```

## Output
The program captures network packets and displays:
- Source IP Address
- Destination IP Address
- Protocol (TCP/UDP)
- Source Port
- Destination Port
